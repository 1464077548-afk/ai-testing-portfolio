2 · 鉴权

所有需鉴权的接口使用个人访问令牌，通过请求头 PRIVATE-TOKEN: <token> 传递； 也支持 Authorization: Bearer <oauth-token>。 缺少或无效的令牌返回 401；令牌有效但权限不足返回 403。 两者不可混用——401 表示「不知道你是谁」，403 表示「知道你是谁，但你不能做」。

防枚举设计：对无权限访问的私有资源，实例刻意返回 404 而非 403， 因为 403 会泄露「该资源存在」。所以调用方校验时应接受 403/404，但绝不能接受 200—— 200 即越权成功。

状态含义调用方应对
401未认证 / Token 失效刷新凭据后重试，不要重算业务逻辑
403已认证但无权限提示权限不足；不要提示重新登录
404资源不存在 或 无权限访问与 403 等同对待，除非确认公开资源

3 · 分页

列表接口统一支持 page / per_page 查询参数， 并在响应头中回传完整分页信息：

响应头含义
X-Page当前页码（必须与请求的 page 一致，否则为回显缺陷）
X-Per-Page每页条数（实测会被夹到 [1,100]）
X-Total总条数
X-Total-Pages总页数 = ⌈X-Total / X-Per-Page⌉
X-Next-Page下一页码（无下一页时缺失）——翻页应以此推进而非 page+1
X-Prev-Page上一页码（无上一页时缺失）
本实例实测边界：per_page=0 → 400； per_page=-1 → 200 且静默回落 20； per_page=101 / 1000 → 200 且被夹到 100。 page=0 / page=-1 均按第一页处理。

4 · 错误结构与状态码语义

错误响应体为 JSON：{"message": "<原因>"}（部分接口为 {"error": ...}）。校验类 400 的 message 会指出具体字段 （如 title can't be blank / name has already been taken）。

状态码语义本实例实测要点
200 / 201 / 202 / 204成功（创建 201；异步/删除标记 202；删除完成 204，部分接口删除返回 200）同一资源不同版本对删除可能返回 200 或 204，客户端两者都要接受
400参数校验失败 / 语义冲突重复删除项目返回 400 “already been marked for deletion”，须当成功处理
401未认证伪造 Token 即 401，不会降级为 200 空列表
403已认证无权限管理员端点对普通 Token 返回 403，匿名返回 401
404资源不存在 / 防枚举遮蔽对资源使用不支持的方法时也返回 404 而非 405（实测）
405 / 406方法/状态不允许MR 合并冲突 405、不可合并 406；未就绪时 409——合并接口的多义结果需按响应体判断
409唯一性冲突标签重名 409；里程碑允许同名，重复创建返回 400 “already being used”
415媒体类型不支持Content-Type: text/plain 提交 JSON 体 → 415（实测）
429触发限流响应含 RateLimit-* 头；客户端应按 Retry-After 退避
5xx服务端缺陷并发创建重名标签实测会冒出 500（已在 QA 用例中 xfail 固化）

畸形 JSON 请求体 → 4xx 且带原因消息；不存在「裸 500」的合法路径。

5 · 标识符与路径规则

id实例级全局唯一编号（如议题的 id 是实例全局的）
iid项目/群组内编号（议题、MR 的对外键）；跨项目必撞，不要当全局键用
路径主键项目/群组既接受数字 id，也接受 URL 编码路径（namespace%2Fproject）；含 / 的分支名、文件路径必须整段编码，否则会被解析成多级路径，表现是不明所以的 404

6 · 删除语义

项目、群组默认走延迟删除：DELETE 后被标记（项目名被改写）， 保留期内可查询、管理员可恢复，到期后物理清除。 本实例保留期经配置为 1 天（默认 30 天，实例可调）。

实测边界：permanently_remove 立即清除只对子群组生效， 顶层群组返回 400 “only available for subgroups”；项目两步清除（DELETE 标记 → DELETE /projects/{id}?permanently_remove=true&full_path=…）， 且标记后项目 path 会被改写，第二步必须用改写后的 path，否则 400。

7 · 已知行为偏差（QA 实测固化）

以下行为在本实例上实测确认，调用方须绕开，QA 套件已用 xfail 固化跟踪：

· 非法日期静默丢弃：议题/里程碑的 due_date 传 2026-02-30 等非法值返回 200/201，但回查为 null——调用方必须回查确认生效。

· 全角空格标题被接受：U+3000 标题得 201，而半角空格/Tab/换行均 400。

· weight 字段 CE 不存在：议题 weight 为 Premium 功能，CE 实例只传 weight 会得到 400 “at least one parameter must be provided”，报错与 weight 无关。

· 并发重名竞态：并发创建同名标签可能冒出 500；同名里程碑可绕过唯一校验落库两条。

接口编号：{域码}-{模块码}-{序号}，如 PRJ-PRJ-001 表示 「项目管理域 · 项目模块 · 第 1 个接口」。编号由生成器从官方 OpenAPI 规范自动编排， 随规范版本演进，引用时建议同时给出方法 + 路径。
